# JKHA Home Improvements website

## Included
- Responsive multi-page website
- Dedicated service pages
- Recent projects and photo placeholders
- MyBuilder review placeholders
- Quote form with multi-photo upload
- Local SEO metadata, structured data, sitemap and robots.txt
- Mobile call button
- No public home address

## Before launch
1. Confirm and purchase `jkhahomeimprovements.co.uk`.
2. Replace project and review placeholders with genuine content.
3. Deploy to Netlify so the quote form can capture enquiries.
4. Add a professional domain email.
5. Review the privacy notice after hosting, analytics and form services are chosen.
6. Create and connect Google Business Profile and Google Search Console.
7. Verify the MyBuilder review wording and attribution before publishing.

## Preview
Open `index.html` in a browser.

## Form note
The quote form uses Netlify Forms markup. File upload functionality needs a compatible hosting/form plan and should be tested after deployment.
